# Contributing to BatchZero

Thank you for contributing to BatchZero!

---

## 1. Development Workflow
1. Fork and clone the repository.
2. Run `npm install` to install dependencies.
3. Test changes using `node --test test/*.test.mjs`.
4. Submit PR against `main` with clear descriptions.

---

## 2. Code Quality
- Follow standard TypeScript lint rules.
- Maintain decoupled business logic under `lib/`.
